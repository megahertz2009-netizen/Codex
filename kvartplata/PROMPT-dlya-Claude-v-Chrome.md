# Задание для Claude, который подключён к Chrome

Вставить целиком в Claude, у которого есть доступ к браузеру
(расширение Claude в Chrome / Claude Desktop с подключением к Chrome).

```
Я уже вошёл в кабинеты в Chrome. Собери кварплату по моим 5 арендным квартирам за последний месяц.

Где смотреть:
- ПИК-Комфорт: new.pik-comfort.ru — начисления/счета по каждому лицевому счёту
- Моя Москва: my.mos.ru — ЕПД по каждой квартире (включая те, что в ПИК: часть услуг могли вынести из ПИК)
- Мосэнергосбыт: lkk.mosenergosbyt.ru — свет по всем 5

Арендатор платит ТОЛЬКО 4 строки:
1. Электроэнергия (Мосэнергосбыт)
2. ХВС
3. ГВС (если две строки — теплоноситель + тепловая энергия — сложи)
4. Водоотведение
Только индивидуальное потребление, строки «на СОИ» не считать. Всё остальное — моё, не арендатору.

По каждой из 4 строк проверь, где она есть:
- только ПИК → берём ПИК
- только ЕПД → берём ЕПД (вынесли из ПИК)
- в обоих → ДУБЛЬ, отметь
- нигде → НЕ ХВАТАЕТ, напиши где искать (Мосводоканал / МОЭК / отключено)

Дай мне:
1. Таблицу: Квартира | Свет | ХВС | ГВС | Водоотв. | ИТОГО арендатору | Не хватает
2. Отдельно по каждой квартире: долг / переплата на начало периода в каждом кабинете
3. Есть ли строка «Услуги связи для целей кабельного вещания» (528,39 ₽) и статус заявок на её отключение в new.pik-comfort.ru/claims/

Ничего не оплачивай и не отправляй без моего подтверждения.
```
