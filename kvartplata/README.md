# Расчёт кварплаты — 5 квартир в аренде

## Вводные

- Квартир: **5**, все сдаются в аренду.
- Данные даёт владелец (скриншоты / выписки из кабинетов). Сам я никуда не захожу
  и ничего не вытягиваю — только считаю по тому, что прислали.
- **Главная сложность:** по части квартир кварплата разбита по разным местам.
  Одна квартира может обслуживаться двумя-тремя конторами сразу, и полный счёт
  собирается только из нескольких кабинетов.

## Модель данных

```
Квартира
 ├── Источник И1 (кабинет УК)        → строки начислений → сумма
 ├── Источник И2 (энергосбыт)        → строки начислений → сумма
 └── Источник И3 (регоператор ТКО)   → строки начислений → сумма
                                        ИТОГО = И1 + И2 + И3
```

Сверка с чек-листом идёт **по квартире целиком**, а не по каждому скрину.
Услуга считается найденной, если она есть хоть в одном источнике.

## Порядок работы

1. Присылаете данные по квартире — одним источником или сразу несколькими.
2. Переношу строки в `kvartiry/<номер>.md`. Скриншоты не сохраняю, только цифры.
3. Сверяю набор услуг по квартире с `spravochnik-uslug.md`.
4. Чего нет — пишу **какой именно услуги не хватает и в каком кабинете её обычно искать**.
   Не ставлю ноль: отсутствие строки ≠ отсутствие начисления.
5. Отдаю блок «Расчёт для клиента» по этой квартире.
6. Присылаете недостающее из другого кабинета — дописываю источник, пересчитываю.
7. Когда все 5 закрыты — общая сводка в `svodka.md`.

## Почему услуги «разъезжаются»

- **Разное дробление у УК.** Одна даёт строку «Содержание жилого помещения»,
  другая ту же сумму разносит на «Содержание» + «Текущий ремонт» + «Управление» +
  «Лифт» + «Уборка МОП». Сумма та же, строк пять.
- **ГВС** бывает одной строкой, бывает двумя: «теплоноситель» + «тепловая энергия».
- **Прямые договоры.** Свет, газ, ТКО, иногда вода и отопление идут напрямую от
  ресурсника мимо УК — в кабинете УК их просто нет, нужен отдельный кабинет.
- **Капремонт** почти всегда отдельная квитанция от Фонда капремонта.
- **СОИ/ОДН** могут уехать в отдельный документ.
- **Домофон, ТВ, охрана** — отдельные подрядчики со своими счетами.
