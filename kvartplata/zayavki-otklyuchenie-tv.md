# Заявки: отключение кабельного ТВ / антенны

Цель — убрать строку за ТВ из начислений по всем 5 квартирам.

## Важно: куда подавать

Строка в квитанции называется по-разному — «Антенна», «Коллективная антенна»,
«Телевидение», «ТВ». Отключает её **оператор связи**, а не управляющая компания.

| Откуда приходит квитанция | Куда подавать заявку |
|---|---|
| ЕПД (mos.ru) | Оператор коллективной антенны. В Москве чаще всего Ростелеком (принял сети Мостелекома). Заявку — оператору, УК её не снимет. |
| ПИК-Комфорт | Заявка в кабинете: **new.pik-comfort.ru/claims/** → новая заявка. Подтверждено владельцем — кабельное по домам ПИК отключается именно там. |

Уточнить оператора можно по самой квитанции: в строке ТВ обычно указан
получатель платежа.

## Что понадобится

- Лицевой счёт по квартире
- Адрес
- Паспортные данные собственника
- Иногда — подтверждение права собственности (выписка ЕГРН)

Заявление подаёт **собственник**. От арендатора не примут.

## Готовый текст заявления

```
Прошу расторгнуть договор на услугу коллективной телевизионной антенны
(кабельного телевидения) по адресу: ____________________________________,
лицевой счёт № ______________.

Услугой не пользуюсь. Прошу прекратить начисление платы за услугу
с ближайшего расчётного периода и произвести отключение оборудования.

Прошу подтвердить расторжение письменно и указать дату, с которой
начисление прекращено.

Собственник: ______________________
Дата: ______________
```

Последний абзац не убирайте — письменное подтверждение с датой понадобится,
если строка не исчезнет из квитанции и придётся требовать перерасчёт.

## Контроль после отключения

1. Отключение вступает в силу **со следующего расчётного периода**, не задним числом.
2. В квитанции за следующий месяц строка ТВ должна исчезнуть.
3. Если не исчезла — предъявляем письменное подтверждение и требуем перерасчёт
   за месяцы после даты расторжения.
4. Пока строка есть — она входит в расчёт для клиента. Убираем её из расчёта
   только после того, как реально пропала из квитанции.

## Связь с расчётом кварплаты

Отключение меняет ежемесячную сумму, поэтому в файлах квартир строку ТВ
до отключения считаем как обычно, а после — фиксируем месяц, с которого
сумма уменьшилась. Для арендных квартир это важно: при смене суммы
начислений нужно пересогласовать, что именно возмещает арендатор.
