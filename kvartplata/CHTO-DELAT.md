ЧТО ДЕЛАТЬ — ПО ШАГАМ
=====================

Две задачи: (1) отключить кабельное ТВ по 5 квартирам, (2) посчитать,
сколько платят арендаторы. Файлы для каждого шага указаны.


ЗАДАЧА 1. ОТКЛЮЧИТЬ КАБЕЛЬНОЕ ТВ (528,39 руб. в месяц с квартиры)
-------------------------------------------------------------------

Шаг 1. Подать 5 заявок в ПИК — по одной на квартиру.

   Открыть файл  Отключение-кабельного.html  (двойной клик, откроется
   в браузере, интернет не нужен).

   Нажать «Кв. 1» → вписать адрес, лицевой счёт, ФИО → нажать
   «Скопировать» под первым документом «Требование об отключении».

   Зайти на new.pik-comfort.ru/claims/ → новая заявка → вставить → отправить.

   ПИК выдаст номер заявки. ЗАПИСАТЬ его в поле «№ прошлого обращения»
   на той же странице — он понадобится для жалоб.

   Повторить для Кв. 2, 3, 4, 5.

   Если квартира не в ПИК — заявку подавать оператору антенны
   (см. Заявки-куда-подавать.txt), не в ПИК.

   Подаёт СОБСТВЕННИК. От арендатора не примут.

Шаг 2. Ждать 10 дней.

   Это срок по закону. Проверить квитанцию за следующий месяц:
   строка «Услуги связи для целей кабельного вещания» должна исчезнуть.

Шаг 3. Если через 10 дней не отключили — жаловаться.

   На той же странице Отключение-кабельного.html, ниже, есть ещё три
   документа: «Поднять старое обращение», «Роскомнадзор», «Роспотребнадзор».

   Подать все три, по каждой квартире отдельно:
   - «Поднять старое» → снова в ПИК, new.pik-comfort.ru/claims/
   - Роскомнадзор  → rkn.gov.ru, раздел обращений
   - Роспотребнадзор → rospotrebnadzor.ru, ВХОДИТЬ ЧЕРЕЗ ГОСУСЛУГИ,
     иначе проверку не назначат

   К каждой жалобе приложить: скрин квитанции со строкой ТВ и скрин
   заявки в ПИК с номером и датой.

   Подробности — Жалобы-ТВ.txt.

Шаг 4. Когда отключат — вычеркнуть строку из расчёта арендатору.
   Пока она есть в квитанции — считается как есть.


ЗАДАЧА 2. ПОСЧИТАТЬ КВАРПЛАТУ АРЕНДАТОРАМ
-----------------------------------------

Арендаторы платят только 4 строки:
   - свет
   - холодная вода
   - горячая вода
   - водоотведение

Всё остальное (содержание, отопление, капремонт, мусор, ТВ) — ваше.

Шаг 1. Сделать скриншоты квитанций за нужный месяц:

   - Мосэнергосбыт — по всем 5 квартирам (свет только там)
   - ПИК-Комфорт — по квартирам в домах ПИК (вода)
   - Моя Москва (mos.ru, ЕПД) — по ВСЕМ 5, включая ПИКовские.
     Нужно, чтобы увидеть, не вынесли ли часть услуг из ПИК.
     Если по адресу пусто — скрин пустого экрана тоже годится.

Шаг 2. Отправить скриншоты в чат. Подписывать не надо.

Шаг 3. Получить обратно по каждой квартире таблицу:

   Услуга          Сумма    Откуда
   Свет            ...      Мосэнергосбыт
   Холодная вода   ...      ПИК или ЕПД
   Горячая вода    ...      ПИК или ЕПД
   Водоотведение   ...      ПИК или ЕПД
   ИТОГО           ...      <- это платит арендатор

   Плюс список: какой строки нет ни в одной квитанции и где её искать.

   Итоги по каждой квартире пишутся в папку квартиры/, общая сводка —
   в Сводка-по-5-квартирам.txt.
