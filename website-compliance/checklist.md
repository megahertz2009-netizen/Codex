# Чек-лист самопроверки сайта другаяклиника.рф

Прогоняется в браузере на холодной сессии (Ctrl+Shift+N — режим инкогнито).
Каждый пункт — это сценарий, по которому автосканер РКН/ИИ-проверка ловит сайты.

## A. Документы

- [ ] `/privacy-policy/` — открывается, актуальная редакция, в шапке есть
  оператор (ООО «Мед Престиж», ИНН), ОГРН, адрес, ответственный за обработку,
  упомянута локализация в РФ, перечислены спец.категории ПДн (здоровье),
  перечислены обработчики (хостер, лаборатория, IP-телефония, CRM).
- [ ] `/consent-pd/` — отдельная страница, отдельный документ. НЕ внутри политики.
- [ ] `/consent-health/` — отдельный документ согласия на спец.категории ПДн.
- [ ] `/cookie-policy/` — отдельная страница, перечень cookie с категориями.
- [ ] `/svedeniya/` — сведения о медорганизации (требование Постановления 736).

## B. Cookie-баннер

- [ ] При первом заходе с пустыми cookie появляется баннер.
- [ ] Кнопки «Принять» и «Отклонить» **равноправные** (одинаковый размер,
  цвет, расположение). Тёмных паттернов нет.
- [ ] **До клика «Принять»** в DevTools → Network нет запросов:
  - mc.yandex.ru/metrika/tag.js (можно ставить только после согласия)
  - google-analytics.com / googletagmanager.com — должны быть СНЯТЫ полностью
  - connect.facebook.net — должны быть СНЯТЫ полностью
  - analytics.tiktok.com — должны быть СНЯТЫ полностью
  - vk.com/rtrg — только после согласия
  - top-fwz1.mail.ru — только после согласия
- [ ] После «Отклонить» трекеры не грузятся при перезагрузке.
- [ ] В футере есть «Настройки cookie» — клик возвращает баннер.

## C. Формы

Применяется к: запись на приём, обратный звонок, заявка на услугу, чат-формы.

- [ ] Чекбокс согласия по умолчанию **пустой**.
- [ ] Текст: «Я даю согласие на обработку персональных данных» с раздельными
  ссылками на «Согласие» и на «Политику».
- [ ] Для медформ — **второй чекбокс** на спец.категории ПДн (здоровье).
- [ ] Кнопка «Отправить» **не активна**, пока обязательные чекбоксы не
  отмечены.
- [ ] Маркетинговое согласие — отдельный, **необязательный** чекбокс.
- [ ] Email — обязателен только если он реально нужен для услуги.
- [ ] При сабмите запрос идёт на сервер в РФ (тот же домен), не на стороннюю
  CRM в США/ЕС.

## D. Реестр операторов РКН

- [ ] На https://pd.rkn.gov.ru/operators-registry/operators-list/ при поиске
  по ИНН **7300040649** ООО «Мед Престиж» **присутствует** в реестре.
  Если нет — подайте уведомление через
  https://pd.rkn.gov.ru/operators-registry/notification/form/ (это первое,
  что найдёт автосканер; штраф 100–300 тыс. ₽ за неуведомление).
- [ ] В уведомлении указаны цели «оказание медицинских услуг», категория
  субъектов «пациенты» и категория данных «специальные категории».

## E. Хостинг и инфраструктура

- [ ] Сайт хостится в РФ. Проверка: `nslookup другаяклиника.рф`, IP должен
  принадлежать российскому ASN (RU).
- [ ] HTTPS включён, валидный сертификат, редирект с HTTP на HTTPS.
- [ ] Почтовый ящик клиники — на российском сервисе (yandex.ru у вас уже ОК).
- [ ] CRM/МИС, куда падают заявки, размещена в РФ. С CRM-провайдером
  заключён договор поручения обработки ПДн.

## F. Реквизиты в футере

- [ ] Полное наименование, ИНН, КПП, ОГРН, юр.адрес.
- [ ] Главный врач, телефон, e-mail.
- [ ] Номер мед.лицензии (Л041-01188-73/02325080), дата выдачи, орган выдачи,
  ссылка на скан и перечень работ (услуг) по лицензии.
- [ ] Ссылки на политику, согласия, cookie-политику и «Настройки cookie» —
  на каждой странице.

## G. Внутренние документы (РКН проверяет на месте/по запросу)

- [ ] Приказ о назначении ответственного за организацию обработки ПДн.
- [ ] Утверждённая Политика обработки ПДн.
- [ ] Положение об обработке ПДн работников и пациентов.
- [ ] Перечень обрабатываемых ПДн.
- [ ] Реестр обработки ПДн.
- [ ] Модель угроз и оценка вреда.
- [ ] Договоры поручения обработки ПДн с хостером, CRM-провайдером,
  оператором IP-телефонии, лабораторией.
- [ ] Журнал учёта согласий и журнал инцидентов.
- [ ] Обязательства о неразглашении со всех сотрудников, имеющих доступ к ПДн.
- [ ] Регламент уведомления Роскомнадзора об инцидентах в течение 24 часов.

## H. Самые дорогие риски (закрыть в первую очередь)

1. **Google Analytics / GTM / Meta Pixel** на сайте → трансграничная передача
   без разрешения РКН → 1–6 млн ₽ юрлицу, повторно до 18 млн.
2. **Не подано уведомление в РКН** → 100–300 тыс. ₽.
3. **Нет согласия отдельным документом** (после 1 сентября 2025) или
   согласие «спрятано» в оферту/политику → до 700 тыс. ₽.
4. **Cookie-баннер с тёмными паттернами** или его отсутствие → до 700 тыс. ₽.
5. **Утечка ПДн без уведомления РКН в 24 часа** → отдельная статья,
   крупные оборотные штрафы.
