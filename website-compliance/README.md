## Что в пакете

| Файл | Куда разместить |

| `privacy-policy.html` | Постоянная страница `/privacy-policy/`, ссылка в футере |

| `footer-snippet.html` | Блок реквизитов в футер каждой страницы |

## Порядок развёртывания

1. Опубликуйте 4 страницы (privacy-policy, consent-pd, consent-health, cookie-policy).
2. Подключите cookie-banner.html — убедитесь, что Метрика и любой другой
   трекер грузятся ТОЛЬКО после клика «Принять».
3. На всех формах (запись на приём, обратный звонок, заявка на услугу,
   чат) замените блок согласий на `form-snippet.html`.
4. Замените футер на `footer-snippet.html`.
5. Снимите с сайта Google Analytics, Google Tag Manager, Meta/Facebook
   Pixel, TikTok Pixel, любые сторонние трекеры с серверами вне РФ.
6. Подайте уведомление в РКН (если ещё не подано).
7. Прогоните чек-лист `checklist.md`.
